# 夕拾 🌿

把日子，一件件拾起来。夕拾是一款 Windows 透明毛玻璃桌面日程软件。

当前版本：**V3.1.0**（2026-10-18，已确认人工验收）。新增每周、每两周、每月、每两个月重复，完善提醒补发和失败重试。完整内容见 [修改日志](CHANGELOG.md)。

解压即用的 Windows x64 ZIP 下载见 [V3.1.0 Releases](https://github.com/chouzing77/xishi/releases/tag/v3.1.0)。包含夕拾.exe、使用说明、首次使用.cmd（创建桌面快捷方式）及许可证。请下载该 ZIP，而不是 GitHub 自动生成的 Source code。

## V3 使用说明

新建待办时选择“日期安排”：单次、连续跨天、每天、每周、每两周、每月或每两个月。除单次外须填写结束日期，最多生成 366 项；连续跨天请选择时间段或全天。月重复遇到不存在的日期取当月末日，下次仍按原始日号。各项独立显示，编辑、完成、删除只影响当前事项或分段。

提醒可选择开始时、提前 5 分钟、提前 15 分钟、自定义提前分钟数或不提醒。全天事项以 09:00 为基准。每 5 秒检查，系统反馈显示后记录成功，失败重试；重启/唤醒补发最近 24 小时未提醒事项。提醒需要保持程序运行并允许系统通知；退出、关机、睡眠时不能即时提醒。新建的近期过期事项也可能立即补发，Windows 勿扰可能影响可见弹窗。

V3 沿用 V2 本机数据目录，使用前请导出 JSON 备份，勿同时运行两个版本。目前不支持无限重复或整组编辑。

## 功能

- 日、周、月视图，按日期分组的全部待办。
- 时间点、时间段、全天事项，分类与完成状态。
- 日 / 周视图点击新建，长按拖动创建时间段。
- 缩小为今日待办卡片；长按完成，完成提示音。
- 透明度调整、窗口置顶、尺寸调整和顶部拖动。
- 本地数据保存、导入导出及备份。

## 本地运行

安装 Node.js 与 npm，在仓库目录执行：

```sh
npm --prefix src install
npm --prefix src start
```

## 构建 Windows 便携版

在 Windows 上执行：

```sh
npm --prefix src run dist
```

产物位于 `src/dist/`。源码保留历史应用标识，以便兼容已有数据；公开产品名称为「夕拾」。

## 检查

```sh
node tests/product-smoke-test.js
node tests/v3-behavior.js
node tests/v31.js
```

自动测试覆盖源码语法、重复日期、月末闰年、提前提醒、补发、失败重试及防重。Windows 原生测试通知返回已显示回执，产品负责人已确认验收；不代表所有设备与系统通知设置均已覆盖。

## 使用说明与边界

桌面版使用本地存储，目前没有账户与云同步，也没有手机版。定时提醒需要保持软件运行并允许系统通知。缩小状态单击卡片不操作，长按切换完成；展开状态可以点击事件编辑。

日程数据和备份属于用户个人数据，不包含在此仓库中。升级或卸载前建议导出备份。下载来源不明的程序前应自行核验。
