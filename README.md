# 夕拾 🌿

把日子，一件件拾起来。夕拾是一款 Windows 透明毛玻璃桌面日程软件。

当前源码：**V3.0.1 测试版**。新增跨天日期安排、日期范围内每天重复及提前提醒，修正下拉选项和滚动条风格。完整内容见 [修改日志](CHANGELOG.md)。

现有可直接使用的 V2.11 下载包见 [Releases](https://github.com/chouzing77/xishi/releases)。本次更新源码，不替换 V2 下载附件。

## V3 使用说明

新建待办时选择“日期安排”：单次事项、连续跨天或每天重复。后两者需要填写结束日期，最多 366 天；连续跨天请选择时间段或全天。生成后每天独立显示，编辑、完成、删除只影响当天或当前分段。

提醒可选择开始时、提前 5 分钟、提前 15 分钟、自定义提前分钟数或不提醒。全天事项以 09:00 为基准。提醒需要保持程序运行并允许系统通知。

V3 沿用 V2 本机数据目录，使用前请导出 JSON 备份，勿同时运行两个版本。目前不支持无限重复或整组编辑。

## 功能

- 日、周、月视图，按日期分组的全部待办。
- 时间点、时间段、全天事项，分类与完成状态。
- 日 / 周视图点击新建，长按拖动创建时间段。
- 缩小为今日待办卡片；长按完成，完成提示音。
- 透明度调整、窗口置顶、尺寸调整和顶部拖动。
- 本地数据保存、导入导出及备份。

## 本地运行

安装 Node.js 与 npm，在仓库目录执行：

```sh
npm --prefix src install
npm --prefix src start
```

## 构建 Windows 便携版

在 Windows 上执行：

```sh
npm --prefix src run dist
```

产物位于 `src/dist/`。源码保留历史应用标识，以便兼容已有数据；公开产品名称为「夕拾」。

## 检查

```sh
node tests/product-smoke-test.js

```

该脚本是源码结构与语法检查，不代表已经完成所有真实鼠标交互、通知和设备兼容性测试。

## 使用说明与边界

桌面版使用本地存储，目前没有账户与云同步，也没有手机版。定时提醒需要保持软件运行并允许系统通知。缩小状态单击卡片不操作，长按切换完成；展开状态可以点击事件编辑。

日程数据和备份属于用户个人数据，不包含在此仓库中。升级或卸载前建议导出备份。下载来源不明的程序前应自行核验。
