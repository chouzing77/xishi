# 夕拾 🌿

把日子，一件件拾起来。夕拾是一款 Windows 透明毛玻璃桌面日程软件。

## 功能

- 日、周、月视图，按日期分组的全部待办。
- 时间点、时间段、全天事项，分类与完成状态。
- 日 / 周视图点击新建，长按拖动创建时间段。
- 缩小为今日待办卡片；长按完成，完成提示音。
- 透明度调整、窗口置顶、尺寸调整和顶部拖动。
- 本地数据保存、导入导出及备份。

## 本地运行

安装 Node.js 与 npm，在仓库目录执行：

```sh
npm --prefix src install
npm --prefix src start
```

## 构建 Windows 便携版

在 Windows 上执行：

```sh
npm --prefix src run dist
```

产物位于 `src/dist/`。源码保留历史应用标识，以便兼容已有数据；公开产品名称为「夕拾」。

## 使用说明与边界

桌面版使用本地存储，目前没有账户与云同步，也没有手机版。定时提醒需要保持软件运行并允许系统通知。缩小状态单击卡片不操作，长按切换完成；展开状态可以点击事件编辑。

日程数据和备份属于用户个人数据，不包含在此仓库中。升级或卸载前建议导出备份。下载来源不明的程序前应自行核验。
